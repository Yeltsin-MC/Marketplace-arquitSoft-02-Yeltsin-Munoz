# Marketplace de productos para mascotas

## Integrante

Yeltsin Wilber Muñoz Corichahua

## Descripción

Marketplace académico de productos para mascotas, tomando como referencia funcional a GoPet.

## Caso de estudio

GoPet como referencia funcional.

## Curso

Arquitectura de Software

## Análisis del sistema

El repositorio contiene:

- Necesidad del negocio.
- Actores.
- Historias de usuario.
- Requisitos funcionales.
- Atributos de calidad.
- Restricciones.
- Drivers arquitectónicos.

## Arquitectura

Se desarrollaron los siguientes elementos:

- Arquitectura inicial en tres capas.
- Decisiones arquitectónicas.
- Estilo arquitectónico basado en monolito modular.
- Enfoque Clean Architecture.
- Diagramas arquitectónicos mediante Mermaid.
