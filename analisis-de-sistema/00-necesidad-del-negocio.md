# Necesidad del negocio

## Problema

Actualmente, la comercialización de productos para mascotas puede encontrarse distribuida entre diferentes vendedores y canales, dificultando que los clientes encuentren, comparen y compren productos desde un único lugar.

## Necesidad

Se requiere una plataforma Marketplace que permita reunir a diferentes sellers en un mismo sistema, facilitando la publicación de productos y el proceso de compra para los clientes.

## Objetivo del negocio

Desarrollar una plataforma que permita:

- Facilitar la búsqueda y compra de productos para mascotas.
- Permitir que diferentes sellers publiquen y gestionen sus productos.
- Centralizar el proceso de compra dentro de una sola plataforma.
- Integrar servicios externos de pago y envío.
- Mantener una arquitectura que permita la evolución del sistema.

## Resultado esperado

Contar con un Marketplace organizado y escalable que facilite la interacción entre clientes, sellers y administradores, permitiendo gestionar productos, compras, pagos y envíos desde una solución centralizada.
