# Atributos de calidad

## Escenario

Durante una campaña comercial, el marketplace podría recibir una gran cantidad de usuarios que consultan productos y realizan compras simultáneamente.

| ID | Atributo de calidad | Escenario de calidad |
|---|---|---|
| AC01 | Rendimiento | Las consultas de productos y las operaciones del carrito deben responder rápidamente incluso con una alta cantidad de usuarios concurrentes. |
| AC02 | Disponibilidad | El sistema debe permanecer disponible durante la campaña comercial para que los usuarios puedan realizar sus operaciones. |
| AC03 | Escalabilidad | El sistema debe soportar un incremento de usuarios y solicitudes sin afectar significativamente su funcionamiento. |
| AC04 | Seguridad | Los datos de los usuarios, las cuentas y las operaciones de compra deben protegerse frente a accesos no autorizados. |
| AC05 | Mantenibilidad | La organización del sistema debe permitir cambios y correcciones sin afectar innecesariamente otras funcionalidades. |
