# Restricciones

| ID | Restricción | Descripción |
|---|---|---|
| RC01 | Aplicación web | El sistema debe ser accesible mediante un navegador web. |
| RC02 | Control de versiones | Los archivos del proyecto deben gestionarse con Git y mantenerse en un repositorio compartido. |
| RC03 | API REST | La comunicación entre la aplicación web y el backend debe realizarse mediante una API REST. |
| RC04 | Pasarela de pago | El sistema debe integrarse con una pasarela de pago externa para procesar pagos. |
| RC05 | Servicio de envío | El sistema debe integrarse con un servicio externo para gestionar la información de entrega de pedidos. |
| RC06 | Arquitectura en tres capas | La propuesta inicial debe organizarse en presentación, lógica de negocio y datos, como exige el ejercicio de diseño de esta guía. |
| RC07 | Documentación en Markdown | Los documentos de análisis y arquitectura del laboratorio deben mantenerse en archivos Markdown dentro del repositorio. |
